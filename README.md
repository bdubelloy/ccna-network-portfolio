# Portfolio Réseau CCNA
## Présentation
Bienvenue sur mon portfolio technique consacré aux réseaux informatiques.

Ce repository rassemble mes laboratoires pratiques, configurations réseau, schémas d'architecture et documentations réalisés dans le cadre de ma montée en compétences en administration réseau.

Mon objectif est de développer et démontrer mes compétences techniques à travers des projets pratiques.

## Compétences travaillées
	► Configuration des équipements Cisco.
	► Segmentation réseau avec VLAN.
	► Routage IPv4.
	► Routage inter-VLAN.
	► Configurations et vérifications des ACL.
	► Routage dynamique OSPF.
	► Analyse et résolution de problèmes réseau.
	► Documentation technique.

## Projets
| Projet | Description | Compétencess |
|--------|-------------|--------------|
VLAN Lab | Segmentation d'un réseau local | VLAN, trunks, switching
Inter-VLAN Routing | Communication entre VLAN | Routage, sous-interfaces
OSPF Lab | Mise en place du routage dynamique | OSPF, IPv4
ACL Lab | Filtrage du trafic réseau | ACL, sécurité



## Environnement de laboratoire
Les projets sont réalisés dans un environnement de simulation ou de virtualisation réseau.

Les équipements, logiciels et versions utilisés sont précisés dans chaque projet.

## Documentation
Chaque laboratoire comprend selon le projet :

	► Les objectifs.
	► Le schéma réseau.
	► Le plan d'adressage.
	► Les configurations.
	► Les procédures de vérification.
	► Les résultats des tests.
	► Les difficultés rencontrées.
	► Les améliorations possibles.
